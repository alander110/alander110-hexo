N1刷iStoreOS系统

一、准备工作

硬件设备

  • 斐讯N1盒子（核心设备）

  • U盘（容量≥8GB，建议准备2个备用）

  • 双公头USB线（用于线刷，建议USB2.0协议）

  • 电源适配器（推荐12V/1A或12V/2A）

  • 网线（千兆或百兆均可）

  • 计算机（推荐Windows系统）

  • HDMI显示器（调试用）

  • USB鼠标/键盘（操作用）

软件工具

  • USB_Burning_Tool：晶晨线刷工具

  • balenaEtcher：镜像烧录工具

  • 降级工具包：用于N1系统降级

  • iStoreOS固件

二、系统降级（如需要）

如果N1盒子是原厂系统且版本高于2.19，需要先降级：

  1. 连接HDMI显示器，查看当前固件版本

  2. 连续点击4次固件版本，开启ADB调试

  3. 记下N1的IP地址

  4. 运行降级工具包中的run.bat

  5. 输入数字”2”选择N1降级

  6. 输入N1的IP地址，等待降级完成

三、制作启动U盘

  1. 下载iStoreOS固件（注意不要解压镜像包）

  2. 打开balenaEtcher，选择下载的固件

  3. 选择目标U盘（会格式化，提前备份数据）

  4. 点击”现在烧录”，等待完成

四、刷入系统

  1. U盘启动iStoreOS, 登录istoreos系统后台,输入默认密码(password)

  2. ip地址可通过

    • 路由器管理员后台
    • Advanced IP Scanner(PC端)
    • WIFIman(手机端)

  3. 执行下面命令: install-to-emmc.sh

  4. 断电、拔U盘、重新插电启动

五、刷电视盒子刷机+救砖详细教程

方法一：正常线刷（推荐）

  1. 安装驱动：安装USB_Burning_Tool时，会弹出驱动安装窗口，选择”始终安装驱动程序软件”

  2. 导入固件：

    • 打开USB_Burning_Tool

    • 点击”文件”→”导入烧录包”

    • 选择iStoreOS固件文件

  3. 配置刷机选项：

    • 取消勾选“擦除flash”和”擦除bootloader”（重要！）

    • 其他选项保持默认

  4. 连接设备：

    • 双公头USB线连接电脑和N1（靠近HDMI的USB口）

    • 先连接USB线，再接通电源

  5. 开始刷机：

    • 点击”开始”按钮

    • 等待进度条达到100%，显示”烧录成功”

    • 点击”停止”，断开USB线和电源

方法二：短接强制刷机（设备无法识别时）

如果正常方式无法识别设备，需要拆机短接：

  1. 拆机：

    • 撕开底部四个防滑垫

    • 拧下四颗T4螺丝

    • 撬开底壳（注意不要翘顶壳）

  2. 找到短接点：

    • 主板上标注的两个触点（通常靠近HDMI接口）

    • 可用镊子、回形针等金属物品短接

  3. 短接刷机：

    • 双公头USB线连接电脑和N1

    • 短接主板上的两个触点

    • 接通电源（保持短接）

    • 听到电脑识别声音后松开短接

  4. 刷入固件：

    • USB_Burning_Tool识别设备后开始刷机

    • 等待进度完成

六、注意事项

  1. 建议先备份重要数据

  2. 刷机过程中不要断电

  3. 如遇问题，可参考B站或恩山论坛的救砖教程

  4. N1功耗仅3W左右，适合7x24小时运行

刷机有风险，操作需谨慎！建议新手在有人指导的情况下进行。
